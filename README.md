# 🌌 Neon Galaxy: Overdrive (v5.8.4.2)

Trò chơi bắn tàu không gian 2D với đồ họa Neon rực rỡ và hệ thống lưu trữ dữ liệu an toàn trên nền tảng đám mây.

🚀 **[BẤM VÀO ĐÂY ĐỂ CHƠI NGAY](https://github.io)**

---

## 🌟 Tính năng nổi bật

- **Progressive Web App (PWA):** Hỗ trợ cài đặt trực tiếp lên màn hình điện thoại/máy tính và chơi ngoại tuyến (Offline) mượt mà nhờ Service Worker.
- **Secure Cloud Sync:** Đồng bộ tài khoản, bảng xếp hạng và tiến trình nhiệm vụ thời gian thực qua Firebase.
- **Hệ thống nâng cấp & Chế tạo:** Sưu tầm nguyên liệu từ Boss, chế tạo linh kiện, ép thẻ nâng cấp sức mạnh súng và vỏ tàu.
- **Chống gian lận (Anti-Cheat):** Tích hợp mã hóa bộ nhớ local bằng CryptoJS và kiểm tra đồng bộ thời gian thực chống hack xu.

## 🛠️ Công nghệ sử dụng

- **Frontend:** HTML5 Canvas, CSS3 (Bloom & Glitch effects), Vanilla JavaScript.
- **Backendless & Database:** Firebase Auth, Cloud Firestore, Security Rules.
- **Libraries:** CryptoJS (Mã hóa lưu trữ), Dicebear API (Tự sinh Avatar bot).

## 🎮 Hướng dẫn chơi

- **Di chuyển:** Vuốt màn hình (đối với điện thoại) hoặc di chuột (đối với máy tính) để điều khiển phi thuyền né đạn quái vật.
- **Tấn công:** Tàu tự động xả đạn. Khi thanh năng lượng đạt 100%, ấn nút **ULT** để kích hoạt siêu kỹ năng quét sạch bản đồ.
- **Nâng cấp:** Tích lũy vàng sau mỗi trận đấu để tiến hóa chỉ số cơ bản trong Cửa hàng.
